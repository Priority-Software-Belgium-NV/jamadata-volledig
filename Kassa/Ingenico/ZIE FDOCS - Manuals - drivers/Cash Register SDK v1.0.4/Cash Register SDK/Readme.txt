=================
Cash Register SDK
=================

- Documentation:
  Contains the "TLV Cash Register Interface Specification" documentation.
  
- Definitions:
  Contains C++ header file and C# source file containing the various enumerations used in the Cash Register TLV messages.
  
- Example Messages:
  Contains a couple of example cash register messages encoded as TLV data (the same as in Appendix C of the "TLV Cash Register Interface Specification" document.
  It is provided to see how the specification translates to the actual encoded data.

- Demo
  Contains a demo cash register application with the C# source code. Needs the .NET 4 Framework installed.
  Note that the source code of the demo application it a bit messy and can be improved on many points.
  But the code can be used as inspiration for implementing the TLV protocol in a language of choice.
